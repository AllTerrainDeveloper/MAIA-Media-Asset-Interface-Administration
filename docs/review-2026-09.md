# App Framework migration and Forms review audit

Reviewed 12–13 September 2026. Source baseline: MAIA `a63b13e`.
Framework reference: `WordPress/openstation` (local `alcazaba-plugin`),
commit `7545b530bf6ba420ebdd647a0d7e418a415d5215`.

## Migration

The library and viewer are now App Framework apps, discovered from `apps/`.
Their ids remain `allterrain-media-explorer` and `atme-viewer`. PHP declares
size, access, state and mount/reopen. The third-party client queue registers
preserved media canvases; the framework owns mounting and teardown. Media
operations remain on the existing shared REST API. Older shells retain the
native callbacks; those callbacks do not replace an existing framework renderer.

Open-time `mediaId` / `wizard` params replace global parking variables and
work with cold opens, singleton reopen and session restore. Stable broadcast
listeners remain available. Existing registration filters and the icon,
commands, drag payloads, opener and relations contracts remain available.

See [architecture](architecture.md), [JavaScript](javascript.md),
[hooks](hooks-reference.md) and [integration](openstation.md).

## Additional defects fixed

- Delayed inspector autosave could write the previous image's text onto the
  newly selected image. Saves retain the edited attachment id.
- AI replies and media loads completing after a window closed could repaint
  or mutate stale state. Closing invalidates those operations; closing the
  explorer before component loading finishes prevents a late mount.
- A second version created within the same second could overwrite the first;
  pruning could then delete a file still referenced by retained history.
  Version basenames are now unique and retained files are asserted to exist.
- An unset versions meta value was cast into a phantom one-element array.
  Facts now count normalized version rows.
- The UI/readme promised the same URL even for format changes. The existing
  behavior changes the extension and URL; the copy now says so. Embedded old
  URLs are not automatically rewritten.
- An empty usage scan claimed a file was safe to delete. It now says no visible
  references were found and acknowledges uses outside the scan.

- Folder drops previously saved silently and left rejected requests unhandled.
  The destination now shows a spinner and “Saving…” until the save and folder
  refresh finish, with a persistent live status for success or failure. The
  same feedback covers external drops into the grid and the bulk filing menu.
  Pending counts survive sidebar repaint and overlapping drops; closing the
  window prevents late feedback or drop-target registration. Regression tests
  cover pending/refresh, navigation, failure/retry, concurrent drops and teardown.

- “New folder” silently nested under the selected folder and folder deletion
  had no UI. Top-level and child creation are now separate actions. Inline
  OpenStation forms replace browser prompts for folder and collection names;
  native confirmation fallbacks are removed. Folder deletion uses the existing
  WordPress term endpoint, with permission and media/child-preservation tests.

## Validation

- TypeScript: `npm run typecheck` passed.
- JavaScript: 99 tests passed across 12 files.
- PHP: 60 tests, 235 assertions passed on the `wordpress-alcazaba` test database.
  Includes real App Framework loading/dispatch, mount/reopen, subscriber and
  anonymous gates, object permissions, batch authorization, private queues,
  malicious replacement files and version history integrity.
- Plugin Check 2.1.0: no blocking findings and no accepted exemptions.
- All six readable/production bundles rebuilt; package generated and checked
  for both `.os.php` definitions, client/runtime assets and license files.
- Browser QA at **http://localhost:8889/wp-admin/**: library loads; image opens
  in the viewer; a second image retargets that viewer; Show in library works;
  AI disclosure appears before dispatch and cancellation closes it without
  invoking the provider. Reload restored the second photo, and the wizard
  opened successfully. A real image drag onto Products showed the folder
  spinner and “Saving…” immediately, then “Filed 1 item into Products.” The
  test refiled an image already in Products, preserving its membership.
  Browser QA also created a sibling with Products selected using the inline
  form, created a child, deleted its temporary parent through the OpenStation
  dialog, and verified the child moved up. Temporary QA folders were removed;
  pre-existing folders were preserved. The final build is deployed there.

The browser pass does not substitute for a full mobile/multisite accessibility
matrix. No live AI-provider request was sent. Existing console errors from
AllTerrain Fields and the shell's component demonstration predate this change;
those sibling plugins were not edited. Cross-format URL rewriting and atomic
locking of simultaneous file replacements remain outside this migration.
